# Kwitansi Generator - Amanah Safar Marhaban

Aplikasi Web Modern **Kwitansi Generator** khusus untuk Travel Umrah & Haji **Amanah Safar Marhaban**.

![Marhaban Kwitansi Generator](marhaban.png)

## 🌟 Fitur Utama

- 🎨 **Multi-Theme Switcher**:
  - **Royal Purple & Amber**: Tema default sesuai warna situs web terkini.
  - **Classic Black & Gold**: Identitas brand lama Marhaban (Hitam Obsidian & Emas Mewah).
  - **Royal Navy & Gold**: Biru Navy Klasik & Emas.
  - **Emerald Green & Gold**: Hijau Islami & Emas.
- ⚙️ **Kop Surat Editable & Dynamic Deletion**:
  - Nama Travel, Nama PT / Legalitas, Nomor Izin PPIU (`23022300424760012`) & PIHK (`23022300424760013`), Alamat, serta Kontak WA & Sosmed.
  - Elemen yang dikosongkan pada pengaturan akan 100% otomatis disembunyikan/dihapus dari Kop Surat.
  - Dukungan Upload Logo Travel Custom PNG/JPG.
- ✍️ **Tanda Tangan Digital & Stempel Resmi**:
  - **Single Signature Block**: TTD Admin Marhaban Tour atas nama **Umar Al-Hasyimi**.
  - **Canvas Draw Pad**: Melukis TTD digital menggunakan mouse atau layar sentuh.
  - **Upload TTD & Stempel**: Unggah file TTD & Stempel cap perusahaan transparan.
- 💰 **Kalkulator Keuangan & Pax Engine**:
  - Rincian Pax Dewasa & Bayi (Infant 0-2 Thn) serta Biaya Add-on Tambahan.
  - Perhitungan Total Biaya Paket, Nominal Dibayar, dan Sisa Tagihan / Kekurangan secara otomatis.
  - Konversi Angka ke Kalimat Terbilang Rupiah Bahasa Indonesia secara otomatis.
- 📋 **Riwayat Transaksi LocalStorage**:
  - Menyimpan, membuka kembali, dan mengedit transaksi kwitansi lama.
- 🖨️ **Exact 1-Page A4 Print Engine**:
  - Layout cetak PDF/Printer yang dioptimalkan agar selalu pas dalam 1 halaman A4 dengan warna yang presisi (`print-color-adjust: exact`).

## 🚀 Cara Menjalankan

Aplikasi dibangun menggunakan HTML5, Vanilla JavaScript (ES6), dan CSS Custom Properties tanpa *dependency* eksternal yang rumit.

1. Clone repositori ini:
   ```bash
   git clone https://github.com/mozakki99/marhaban-kwitansi-generator.git
   cd marhaban-kwitansi-generator
   ```
2. Buka file `index.html` langsung di browser favorit Anda, atau jalankan web server lokal:
   ```bash
   python3 -m http.server 8888
   ```
3. Akses aplikasi melalui `http://localhost:8888`.
